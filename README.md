### Featured Projects

- [**aws-edge-federated-learning**](https://github.com/HopeItsAvailable/aws-edge-federated-learning)  
  Distributed federated learning setup across a Raspberry Pi edge node and 10 EC2 instances using PyTorch, AWS IoT Greengrass, and MQTT for round synchronization to train a CNN without centralizing data.

- [**elastic-iaas-image-classifier**](https://github.com/HopeItsAvailable/elastic-iaas-image-classifier)  
  AWS-based image classifier with a custom autoscaling controller that scales 0 to 15 EC2 instances based on SQS queue depth, using a warm cache to keep inference latency under 1s.
